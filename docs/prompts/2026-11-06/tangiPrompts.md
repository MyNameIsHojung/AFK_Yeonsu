# 탱이(펫) 이미지 프롬프트 (Codex 이미지 생성용)

`scripts/genTangi.sh` 가 사용. 원문 영어 프롬프트는 스크립트의 `STYLE` / `STAGES` / `FRAME_DESCS` 참고.

## 참고 이미지
- 단계 기본: 탱이 사진(`base_img/F8C46FA3-…_1_105_c.jpeg`, 성체) + 연수 그림체 참고(`public/assets/yeonsu/stage1.png`, 소년은 그리지 않음)
- 프레임: 해당 단계 기본 이미지 + 탱이 사진 (외형·크기·위치 유지, 자세/표정만 변경)
- 모두 투명 배경 옵션 사용

## 단계별 외형
| 단계 | 내용 |
|---|---|
| 1 | 아기 강아지 (성체보다 훨씬 작고 통통), 하늘색 턱받이 |
| 2 | 어린 강아지, 노란 모자 + 작은 노란 가방 |
| 3 | 사진 같은 성체, 흰 머리띠 |
| 4 | 작은 남색 넥타이 + 사원증 |
| 5 | 빨간 땀밴드 + 미니 덤벨 |
| 6 | 작은 금관 + 짧은 빨간 망토 |
| 7 | 흰·주황 강아지 우주복 + 투명 헬멧 |
| 8 | 금빛 후광 + 작은 천사 날개 |
| 9 | 별 박힌 남색 망토 + 은하 펜던트 |

## 프레임
| 키 | 내용 |
|---|---|
| (기본) | 앉아서 고개 갸웃 |
| blink | 같은 자세, 눈 감음 |
| act | 꼬리 흔들며 혀 내밀기 |
| happy | 눈웃음 + 분홍 하트 |
| dig | 네 발로 서서 앞발로 땅 파기, 흙 튀김 |

## 메모
- stage3_act(상단 흐릿한 띠 + 귀 잘림), stage4_happy(반투명 배경 상자)는 재생성함
