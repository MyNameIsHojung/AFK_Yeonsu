# 집 배경 + 프레임 애니메이션 계획

## 1. 문제
- 캐릭터가 크림색 단색 이미지를 둥근 카드에 넣은 형태라 "집에서 키우는" 느낌이 없음
- 정지 이미지라 살아있는 느낌이 없음

## 2. 단계별 집 배경 (Codex, 캐릭터 없는 방 그림 6장)
같은 치비 카툰 그림체, 정면 눈높이 시점, **가운데 바닥을 비워 캐릭터가 설 자리** 확보

| 단계 | 방 | 주요 소품 |
|---|---|---|
| 1 아기 | 아기방 | 아기 침대, 모빌, 놀이매트, 장난감 |
| 2 초딩 | 어린이 방 | 이층 침대, 장난감 상자, 크레파스 책상 |
| 3 수험생 | 공부방 (밤) | 스탠드 켜진 책상, 쌓인 문제집, 포스트잇 벽 |
| 4 직장인 | 자취 원룸 | 소파, 노트북 책상, 컵라면, 빨래 건조대 |
| 5 헬창 | 거실 홈짐 | 덤벨 랙, 요가매트, 프로틴 쉐이커 |
| 6 전설 | 펜트하우스 거실 | 샹들리에, 트로피 장식장, 통창 야경 |

## 3. 캐릭터 투명 배경
- 테스트 결과: Codex 이미지 생성 도구의 투명 배경 옵션 동작 확인 (`hasAlpha: yes`, 테두리 깔끔)
- 기존 24장 처리: 배경이 단색 + 굵은 외곽선이라 **가장자리 flood-fill 로 배경만 제거** (그림 자체는 그대로 유지)
  - 결과가 지저분하면 해당 장만 Codex 투명 재생성
- 새로 만드는 프레임은 처음부터 Codex 투명 배경으로 생성

## 4. 프레임 애니메이션
### 캐릭터 대기 루프 (단계별 프레임 3장)
| 프레임 | 내용 |
|---|---|
| idle (기존 stageN) | 기본 자세 |
| blink (신규) | 같은 자세, 눈 감음 |
| act (신규) | 단계별 동작 한 컷 — 아기: 젖병 빨기 / 초딩: 손 흔드는 각도 변경 / 수험생: 필기 / 직장인: 커피 마시기 / 헬창: 덤벨 들어올림 / 전설: 망토 휘날림 |

- 재생 순서 예: `idle(1.2s) → act(0.4s) → idle(1.0s) → blink(0.15s)` 반복 (손그림 애니메이션 느낌)
- 프레임 사이엔 CSS 숨쉬기(살짝 위아래 늘었다 줄었다) + 바닥 그림자
- 탭 시 기존 표정 프레임 → 끝나면 대기 루프 복귀
- 신규 이미지: blink 6 + act 6 = **12장** (Codex, 약 12분)

### 배경 애니메이션 (코드 오버레이, 이미지 추가 없음)
- 현실 시간 기준 낮/저녁/밤 색감 변화
- 떠다니는 먼지/빛 입자, 창문 햇살 깜빡임
- 단계별 소소한 효과: 3단계 스탠드 불빛 일렁임, 4단계 컵라면 김, 6단계 반짝이
- 진화 시 방 전환 연출 (페이드 + 캐릭터 점프)

## 5. 화면 구성 변경
- 기존 둥근 카드 → 가로 전체를 채우는 **방 장면** (정사각형, 캐릭터는 바닥 중앙)
- HUD(연수력)는 장면 위 반투명 바로 겹쳐서 표시

## 6. 작업량 / 순서
1. 배경 6장 생성 → 사용자 확인
2. 기존 24장 배경 제거 (로컬 스크립트)
3. blink/act 12장 생성
4. 장면 레이아웃 + 프레임 재생기 + 배경 효과 구현
5. 브라우저 확인

Codex 생성 총 18장 (약 20분)
