# 방치형 연수 키우기 — 구현 계획

## 1. 목표
- 브라우저에서 돌아가는 **방치형(Idle) 육성 게임**
- 주인공 "연수"는 `base_img/` 사진 4장을 기반으로 **Codex(이미지 생성)** 가 만든 캐릭터 이미지 사용
- 게임 코드는 Claude, 이미지 에셋은 Codex 담당

## 2. 기술 스택
| 항목 | 선택 | 이유 |
|---|---|---|
| 플랫폼 | 웹 (PC/모바일 브라우저) | 설치 없이 바로 실행, 공유 쉬움 |
| 빌드 | Vite + TypeScript (프레임워크 없음) | 가볍고 빠름, 게임 루프 단순 |
| 저장 | localStorage + 오프라인 보상 계산 | 서버 불필요 |
| 이미지 | `codex exec -i base_img/*.jpeg` 로 PNG 생성 | 사용자 요청 |

## 3. 게임 디자인 (v1 범위)

### 핵심 루프
1. 연수를 **탭** → "연수력(💪)" 획득
2. 연수력으로 **업그레이드** 구매 → 초당 자동 획득량 증가
3. 누적 연수력이 기준치 도달 → **성장 단계 진화** (이미지 변경)
4. 앱을 꺼도 **오프라인 시간만큼 보상** (최대 8시간)

### 성장 단계 (단계별 Codex 이미지 1장)
| 단계 | 이름 | 컨셉 |
|---|---|---|
| 1 | 아기 연수 | 젖병 문 아기 |
| 2 | 초딩 연수 | 책가방 멘 초등학생 |
| 3 | 수험생 연수 | 머리띠 + 문제집 |
| 4 | 직장인 연수 | 정장 + 노트북, 피곤한 눈 |
| 5 | 헬창 연수 | 근육질 + 덤벨 |
| 6 | 전설의 연수 | 왕관 + 망토, 빛나는 오라 |

### 업그레이드 (초당 생산 건물형, 6종)
간식 먹이기 → 낮잠 → 유튜브 시청 → 공부 → 운동 → 명상 (가격 1.15배씩 증가, 표준 idle 공식)

### 부가 요소
- 탭 시 표정 변화(기본/웃음/놀람 — `base_img` 표정 4종 활용) + 숫자 팝업
- 랜덤 이벤트: 가끔 "배고픈 연수" 등장 → 탭하면 보너스
- 진화 시 연출(플래시 + 축하 문구)

> v1 제외(나중에): 환생/프레스티지, 사운드, 업적, 클라우드 저장

## 4. 이미지 파이프라인 (Codex)
- 스크립트: `scripts/genImages.sh` — 프롬프트 목록을 돌며 `codex exec` 호출
- 입력: `base_img/*.jpeg` 를 `-i` 로 첨부 (얼굴 특징 유지: 일자 앞머리, 짙은 눈썹, 동그란 얼굴)
- 공통 스타일 프롬프트: **귀여운 2D 치비 카툰, 큰 머리, 굵은 외곽선, 투명 배경 PNG, 512×512** — 단계별 일관성 유지
- 출력: `public/assets/yeonsu/stage{1..6}.png`, `expr_{happy,surprised,sleepy}.png`, `public/assets/bg/room.png`, 업그레이드 아이콘 6종
- 프롬프트 원문은 `docs/prompts/2026-11-06/imagePrompts.md` 에 기록
- 생성 전 **1장 시범 생성 → 스타일 확인 → 나머지 일괄 생성** 순서로 진행

## 5. 폴더 구조
```
AFK_Yeonsu/
├─ base_img/            # 원본 사진 (수정 안 함)
├─ public/assets/       # Codex 생성 이미지
├─ scripts/genImages.sh
├─ src/
│  ├─ main.ts           # 부트스트랩, 게임 루프
│  ├─ state.ts          # 상태 + 저장/불러오기 + 오프라인 보상
│  ├─ data.ts           # 단계/업그레이드 수치
│  ├─ ui.ts             # DOM 렌더링
│  └─ style.css
└─ index.html
```

## 6. 진행 순서
1. Vite 프로젝트 생성 + 플레이스홀더(원본 사진 크롭)로 게임 로직 완성 → 브라우저에서 동작 확인
2. Codex로 시범 이미지 1장 생성 → 사용자 스타일 확인
3. 나머지 이미지 일괄 생성 → 게임에 연결
4. 밸런스 조정 + 모바일 레이아웃 확인
