# 탱이 (펫) 계획 — v2

참고 사진: `base_img/F8C46FA3-…_1_105_c.jpeg` — **성체** 하얀 복슬 강아지, 접힌 귀, 까만 동그란 눈, 그려진 눈썹, 분홍 볼터치

## 1. 등장
- 상점에 세 번째 탭 **🐶 탱이**
- 처음엔 `🐾 탱이 입양하기` (1,000) 카드만 → 입양하면 방에 아기 탱이 등장
- 연수 옆을 졸졸 따라다님 (총총 걸음, 방향 반전), 멈추면 앉아서 꼬리 흔들기
- 탱이를 탭하면 하트 + 좋아하는 표정 + 보너스 (탭 값의 50%)

## 2. 탱이 성장 (레벨 → 9단계 외형 진화)
- 🍖 **간식 주기**: 탱이 레벨 +1 (가격 1,000 × 1.6^레벨), 레벨당 탱이 능력 +5%
- 정해진 레벨에서 **진화** (외형 변경 + 탱이 능력 ×1.5, 진화 연출)
- 단, 탱이 단계는 **연수 단계를 넘을 수 없음** (주인과 같이 큼)
- 1~2단계는 강아지(작게), 3단계부터 사진 같은 성체 크기

| 단계 | 이름 | 조건 | 외형 (연수 단계와 같은 테마) |
|---|---|---|---|
| 1 | 아기 탱이 | 입양 | 꼬물꼬물 아기 강아지 + 턱받이 |
| 2 | 꼬마 탱이 | Lv.5 | 어린 강아지 + 노란 모자·작은 가방 |
| 3 | 공부견 탱이 | Lv.10 | 성체 + 흰 머리띠 |
| 4 | 직장견 탱이 | Lv.15 | 작은 넥타이 + 사원증 |
| 5 | 헬스견 탱이 | Lv.20 | 땀밴드 + 미니 덤벨 |
| 6 | 전설의 탱이 | Lv.25 | 왕관 + 빨간 망토 |
| 7 | 우주견 탱이 | Lv.30 | 강아지 우주복 + 투명 헬멧 |
| 8 | 천상견 탱이 | Lv.35 | 후광 + 작은 천사 날개 |
| 9 | 차원견 탱이 | Lv.40 | 별이 박힌 망토 + 은하 목걸이 |

참고 가격: Lv.10 ≈ 11만, Lv.20 ≈ 1,200만, Lv.30 ≈ 13억, Lv.40 ≈ 1,300억

## 3. 탱이 능력 (레벨형, 위 성장 배수가 모두 곱해짐)
| 항목 | 효과 | 시작 가격 | 가격 증가 |
|---|---|---|---|
| 🐾 꼬리 콕콕 | 탱이가 연수를 대신 톡 (자동 탭, 크리티컬 적용). 4초 → 레벨당 -0.3초, 최소 1초 | 2,000 | ×2 |
| 🦴 보물 찾기 | 60초마다 보물: 초당 생산량 × (20 + 10×레벨)초 | 5,000 | ×2.5 |
| 💕 우정 | 모든 생산량 +10% / 레벨 (더하기) | 1만 | ×2.2 |

## 4. 탱이 이미지 (Codex, 투명 배경, 연수와 같은 치비 그림체)
- 단계별 5장: 기본(앉아 갸웃) · 눈 감음 · 꼬리 흔들기 · 좋아함(하트) · 땅 파기
- 9단계 × 5장 = **45장, 약 60분**
- 1단계 기본 1장을 먼저 시범 생성 → 그림체 확인 후 나머지

## 5. 전설의 기운 가격 완화 (이번에 함께 반영)
- 가격 증가 ×3 → **×1.5** (Lv.5 40.5억 → 2.5억, Lv.10 9,840억 → 19.2억) — 탱이보다 먼저 배포

## 6. 저장 호환
- 새 값(입양 여부, 탱이 레벨, 능력 레벨 3종)은 기본값 → 기존 진행 영향 없음

## 7. 순서
1. 탱이 1단계 기본 시범 생성 → 확인
2. 나머지 44장 생성 (중간중간 검토)
3. 탭·성장·능력·따라다니기 구현 → 브라우저 확인 → 배포
