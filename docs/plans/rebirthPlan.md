# 환생 시스템 + 10~12단계 계획

## 1. 환생
- **조건**: 연수 6단계(전설의 연수) 도달
- **결과**: 완전 초기화 — 연수력·단계·업그레이드·자동 생산·탱이(입양 포함) 전부 처음으로. **환생 횟수만 유지**
- **보상**: 환생 횟수 N 당 **모든 획득 ×2ⁿ** (1회 ×2, 2회 ×4, 3회 ×8 …)
  - 적용 대상: 자동 생산, 탭(크리티컬 포함), 탱이 탭·꼬리 콕콕·보물, 배고픈 연수 이벤트, 오프라인 보상
  - 계산 순서: 다른 모든 배수를 계산한 **맨 마지막에 곱함**
  - 단계 진행 기준(누적 연수력)도 이 배수로 쌓인 값을 그대로 사용 → 환생할수록 빨리 성장
- **UI**
  - 상단 바: 단계 옆에 `♻ 환생 N회 · ×2ⁿ` 배지 (0회면 숨김)
  - 6단계 이상이면 상단에 `♻ 환생` 버튼 등장 → 확인 창 ("모든 진행이 처음으로 돌아가요. 획득 ×2ⁿ → ×2ⁿ⁺¹")
  - 환생 연출: 화면 하얗게 → 아기 연수로 새 시작 + "♻ N번째 환생!" 창
- **저장**: `rebirths` 값 추가 (기존 저장은 0회로 시작), 저장 키 유지

## 1-1. 구현 메모 (2026-11-06)
- 환생 조건: 6단계(전설의 연수)부터 — 사용자 요청으로 9단계에서 하향
- 배수 적용: powerPerSec / tapValue 의 마지막에 ×2ⁿ (나머지 획득은 이 둘을 기반으로 계산되므로 한 번만 곱해짐), 이벤트 최소 보상도 ×2ⁿ
- 환생 버튼(♻)은 6단계 이상일 때 상단에 표시, 확인/취소 창 → 저장 후 새로고침, 다음 화면에서 "N번째 환생!" 창
- "처음부터 다시하기"는 환생 기록까지 삭제

## 1-2. 탱이 진화 조건 변경 (같이 반영)
- 진화 필요 레벨 단계마다 ×3: 3 · 9 · 27 · 81 · 243 · 729 · 2187 · 6561
- 간식 가격: 누적 = 30 × Lv^2.9 (진화 레벨까지 누적 가격이 연수 단계 기준과 비슷), 레벨당 탱이 능력 +5% → +1%
- 간식 주기 카드에 수량 버튼 (×1 / ×10 / ×100 / 최대)

## 2. 10~12단계 (나중에 — 사용자 요청으로 보류)
| 단계 | 이름 (안) | 필요 누적 | 방 | 탱이 |
|---|---|---|---|---|
| Lv.10 | 시간의 지배자 연수 | 100조 | 거대한 시계 톱니가 도는 시간의 방 | 회중시계 목걸이 탱이 |
