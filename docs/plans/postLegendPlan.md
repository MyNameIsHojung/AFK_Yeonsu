# 전설 이후 단계 + 자동생산 배수 + 크리티컬 계획

## 1. 추가 단계 (7~9)
기준은 기존처럼 **누적 획득 연수력**, 단계당 생산 보너스 +50% 유지.

| 단계 | 이름 (안) | 필요 누적 | 방 (집 컨셉 유지) | 동작 컷 |
|---|---|---|---|---|
| Lv.7 | 우주 연수 | 30억 | 우주정거장 개인 숙소 (창밖 지구, 무중력 소품) | 우주복 헬멧 쓰고 둥실 |
| Lv.8 | 연수신 | 1,000억 | 구름 위 천상의 거실 (금빛 기둥, 구름 소파) | 후광 + 손짓으로 빛 뿌리기 |
| Lv.9 | 차원을 넘은 연수 | 3조 | 은하가 흐르는 차원의 방 (떠다니는 가구) | 손끝에서 작은 은하 |

- 단계당 Codex 이미지 7장 (기본·표정 3·깜빡임·동작 = 6, 방 1) → **총 21장, 약 25분**
- 6단계처럼 처음부터 투명 배경으로 생성

## 2. 자동생산 배수 업그레이드 (Lv.6 전설부터 등장)
| 항목 (안) | 효과 | 시작 가격 | 가격 증가 |
|---|---|---|---|
| 🌟 전설의 기운 | 자동 생산 ×1.2 / 레벨 (곱연산: Lv.5 ≈ ×2.5, Lv.10 ≈ ×6.2) | 5천만 | ×3 / 레벨 |

- 초안(×2 / 레벨, 가격 ×10)은 레벨당 효과가 너무 커서 하향 (2026-11-06 사용자 피드백)
- Lv.10 가격 ≈ 3조 → 9단계 도달 무렵 Lv.10 근처가 되도록 맞춤

- 탭 값 중 "초당 생산량의 2%" 부분에도 자연스럽게 반영됨
- 최대 레벨 없음 (가격으로 제한)

## 3. 크리티컬
기본: **확률 5%, 크리티컬 시 ×1.2**

| 항목 (안) | 효과 | 시작 가격 | 가격 증가 | 최대 |
|---|---|---|---|---|
| 🎯 급소 찌르기 | 크리티컬 확률 +1%p / 레벨 | 100 | ×1.6 | 50% (Lv.45) |
| 💥 한 방의 힘 | 크리티컬 배율 +0.1 / 레벨 | 200 | ×1.8 | 없음 |

- 연출: 큰 빨간 "크리티컬! +N" 숫자 + 화면 살짝 흔들림 + 놀람 표정
- 등장 시점: 급소 찌르기 = 처음부터, 한 방의 힘 = 크리티컬 확률 1레벨 구매 후

## 4. 하단 키우기 바 정리
항목이 7개 → 10개가 되어 한 줄에 다 들어가지 않음 → **탭 2개로 분리**
- `자동 생산` : 간식 ~ 명상 6종 + 전설의 기운
- `클릭 강화` : 손가락 단련 + 급소 찌르기 + 한 방의 힘
- 각 탭 안에서 기존처럼 순차 등장, 새 항목이 생긴 탭엔 빨간 점 표시

## 5. 기존 진행도 영향
- 없음. 새 레벨 값들은 저장 데이터에 없으면 0 으로 시작 (기존 저장 키·항목 id 유지)

## 6. 순서
1. 크리티컬 + 배수 업그레이드 + 탭 UI (기존 이미지로 바로 테스트 가능) → 배포
2. 7~9단계 이미지 생성 → 검토 → 연결 → 배포
